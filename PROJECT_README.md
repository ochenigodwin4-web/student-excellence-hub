# Student Excellence Hub

A comprehensive platform designed to improve students' society skills and academic excellence through interactive tools, resources, and community engagement.

## Tech Stack

- **Frontend:** React.js
- **Backend:** Django (Python)
- **Database:** PostgreSQL
- **API:** Django REST Framework

## Features

- 📚 Academic Resources & Study Materials
- 🤝 Social Skills Development Programs
- 📊 Progress Tracking & Analytics
- 👥 Community Forums & Peer Support
- 🎯 Goal Setting & Achievement Tracking
- ⏱️ Time Management Tools
- 🏆 Gamification & Badges System

## Getting Started

### Prerequisites
- Python 3.9+
- Node.js 14+
- PostgreSQL

### Backend Setup
```bash
cd backend
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

### Frontend Setup
```bash
cd frontend
npm install
npm start
```
